# Decisions Log

Dated record of go/no-go and architecture decisions made during the build. Append, never rewrite
history.

## Format

```
## YYYY-MM-DD — <decision title>
**Context:** why this decision was needed
**Decision:** what was decided
**Rationale:** why
```
